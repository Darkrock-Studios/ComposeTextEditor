LineBox

data class LineBox(val left: Float, val top: Float, val width: Float, val height: Float, val startsBand: Boolean, val endsBand: Boolean)(source)

A line's box in content space, the coordinates LineWrap.offset is in, when it is laid out beside other lines, as a table row's cells are. The lines laid out together share a band from top, height tall: as tall as the tallest of them, and moving the lines after it down by that once. startsBand and endsBand tell its first and last lines.
