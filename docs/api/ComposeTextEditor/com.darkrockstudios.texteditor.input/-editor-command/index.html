EditorCommand

sealed interface EditorCommand(source)

An editor operation, named by intent rather than by the keys that trigger it. KeyBindings maps a platform's key chords onto these.

class Action(val id: String, val isEdit: Boolean) : EditorCommand

A named operation. Identified by id rather than enum membership so a host can introduce its own (Action("myapp.toggleBold", isEdit = true)) and bind it from a custom KeyBindings exactly like a built-in. Ids are namespaced by convention (editor. is the built-ins'), and equality is by id alone, so two actions sharing an id are the same action however they disagree on isEdit.
