val Yank: EditorCommand.Action

Inserts what the last kill deleted, over any selection: Cocoa's Ctrl+Y. Deleting to the line's start or end or the paragraph's end is a kill, which keeps what it deletes in the editor's own kill buffer, never the clipboard.
