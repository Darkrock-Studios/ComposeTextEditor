isCtrlShortcut
Link copied to clipboard
val KeyEvent.isCtrlShortcut: Boolean

A Ctrl chord that is a real shortcut rather than an AltGr composition. Windows synthesizes AltGr as left-Ctrl + right-Alt, so a Ctrl-only test steals the layout chords that type a character (Hungarian AltGr+X is #, Polish AltGr+Z is ż). Compose folds AltGraph into isAltPressed, and no Ctrl+Alt chord is bound.
