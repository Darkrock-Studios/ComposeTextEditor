TabSettings

data class TabSettings(val size: Int = 4, val insertTabCharacter: Boolean = false, val movesFocus: Boolean = false)(source)

What Tab and Shift+Tab do in one editor, set on TextEditorState.tabSettings.

However this is set, the keyboard can always leave the editor: Ctrl+Tab and Ctrl+Shift+Tab move focus (as in GTK, Cocoa and Swing text views), and so does a Tab pressed straight after Escape (as in CodeMirror), for browsers that keep Ctrl+Tab for themselves.
